# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to [security@tokenpak.ai](mailto:security@tokenpak.ai).
Include the affected version, a concise reproduction, and the expected and
observed behavior. Do not open a public issue for an unpatched vulnerability.

This repository contains public documentation. For package behavior and release
status, see the current documentation and the `tokenpak/tokenpak` repository.
