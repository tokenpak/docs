# TokenPak Documentation

This repository builds the public documentation for TokenPak, the local proxy
that packs AI requests before they reach a provider and records what changed.

It is for developers evaluating, installing, or operating the open-source
`tokenpak` package. Start with the [Quick Start](docs/QUICKSTART.md), then use
the [client guides](docs/guides/claude-code.md), [CLI reference](docs/cli-reference.md),
and [troubleshooting guide](docs/troubleshooting.md) as needed.

The package source and release notes live in
[tokenpak/tokenpak](https://github.com/tokenpak/tokenpak); protocol schemas and
adapter metadata live in [tokenpak/registry](https://github.com/tokenpak/registry).
